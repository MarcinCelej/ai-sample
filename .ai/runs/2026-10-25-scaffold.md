## Decisions and assumptions (gaps the spec did not cover)

- **Audit:** `CreatedBy`/`UpdatedBy` are `Guid?` (Identity user ID). `UpdatedAt` stays null until the first update.
- **Course:** `Name`, `Description?`, `Capacity`, `MonthlyFee`, `Status` (`Active`/`Archived`), with a non-unique index on `(TenantId, Name)`.
- **`GetCourses`:** lists active courses only, as the public catalog. The handler returns the page directly, because a query without expected failures needs no `Result`.
- **`Location` header:** `CreateCourse` returns `Location: /api/courses/{id}`, but there is no `GetCourse` endpoint yet.
- **Validation:** handlers and validators are registered explicitly, like handlers (no assembly scanning).
- **Problem shape:** the validation problem carries `errorCodes` next to `errors`, plus `code`. Antiforgery failures return `400` with `code: antiforgery.invalid`.
- **SPA fallback:** `/api/*` routes without an endpoint return 404, not `index.html`.
- **Startup without a database:** the connection string is read lazily, and design-time EF tools work without one (`EF.IsDesignTime`).
- **Tests:** integration tests use header-based test auth (`X-Test-User`, `X-Test-Roles`) and tenant (`X-Test-Tenant`), run sequentially, and reset with Respawn.

## Deviations from the spec (spec updated in this commit)

- **Identity context:** does not derive from `ModuleDbContext`, as decided above.
- **Backend coverage:** `coverlet.MTP` instead of `coverlet.collector`. xUnit v3 4.x runs only on Microsoft.Testing.Platform, which `backend/global.json` enables.
- **Public migrations:** EF-generated migrations are `public`; the public-surface architecture rule exempts `Persistence/Migrations`.
- **Orval:** `fetch.includeHttpResponseReturnType: false`, so hooks return the body and non-2xx responses throw `ApiError`.
- **ESLint:** version 9. Feature isolation uses `no-restricted-imports`, because `eslint-plugin-import` does not support ESLint 10 and `eslint-plugin-jsx-a11y` does not either.
- **shadcn:** Radix base, and `cn()` lives in `lib/utils.ts` (shadcn convention) instead of `lib/cn.ts`.
- **Spec additions:** the Shared folders `Paging/` and `Domain/`, `DisableTransitiveProjectReferences`, and `--output-dir` in the migrations command.

## Review outcome

- **Review:** backend build had 0 warnings; unit tests 59/59; architecture tests 24 passed and 2 skipped (modules without dependencies); frontend lint, typecheck, test (24/24) and build passed.
- **Local run:** the API was run against the dev SQL Server and applied the `identity` and `courses` migrations. Smoke tests: `GET /api/courses` returned 200; an invalid `pageSize` returned 400 with codes; an anonymous `POST` returned 401; an unknown `/api` route returned 404; the SPA proxy worked.
- **Incident:** "Docker is not installed" was wrong. Testcontainers used Podman, and a leftover SQL Server container starved the local Podman machine. The connection string also needed `127.0.0.1`. See lesson `local-containers-and-sql-host`.
